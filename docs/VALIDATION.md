# 验证状态

本文件不预填或伪造成功记录。提交附带 50 项仅离线单元测试，覆盖标签隔离、语言分组、配置约束、HTTP 响应解析、缺 usage、预算、错误后停止、日志去敏、统计、配对比较和 CLI。

请以本提交 GitHub Actions 的真实 job 日志为准。`python -m unittest discover -s tests -v` 可在本机重复。测试假响应的模型名为 test-fake-not-jev，它们只验证程序，不能作为 Jev 跑分。

没有 TypeSafe 或 LLM 密钥，没有在本次实现中进行真实付费 API 调用；没有下载权重、运行社区推理引擎、测用户显存或执行真实长任务。CI 仅运行 Python 标准库离线测试、生成样本、规则组、Jev dry-run 及数学故障模拟；不读取任何仓库 secret。

即使所有离线测试通过，也只说明这些程序行为符合测试约定，不证明供应商接口实连、判断质量、中文适用性或生产可靠性。
